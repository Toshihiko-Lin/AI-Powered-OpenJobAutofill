AI-Powered OpenJobAutofill

维护本机简历资料

数据只保存在本机浏览器里，不会走同步云端。AI 只辅助识别表单字段和可匹配的资料项，不会读取你的简历值。点击开始填写后会自动填写能确定的字段，待处理字段可在资料面板查看和手动复制。

首次使用

三步开始网申填写

  1. 填写资料 先在下面按模块维护本机简历资料。
  2. 保存资料 点击底部“保存资料”，看到浮层提示后就已保存到本机。
  3. 开始填写 打开招聘表单页，点击插件图标里的“开始填写”。

AI 页面分析是可选增强：如果希望模型辅助理解表单字段，再到下方 API 设置填写 API Key、Base URL 和模型名。测试 API 连接只验证当前表单值，点击“保存 API 设置”后才会用于填写。不配置 API 时仍可使用本地规则填写。

资料目录

简历资料

这里按通用网申栏目拆开填写。保存后资料只保存在本机浏览器里，需要迁移或备份时再导出资料备份。

上传简历自动解析（可选）

支持 PDF、DOCX、TXT、MD。文本在本机提取后，会把简历全文发送到下方配置的 API，由模型拆分到各模块字段。这是唯一会把简历具体内容发给 AI 的功能，点击后会再次确认。解析结果只写入编辑区，检查无误后再点“保存资料”。

资料加载后，编辑任意字段会在这里提示是否需要保存。

版本更新

插件会定期检查 GitHub Release。发现新版本时，浏览器图标会显示 NEW；更新前建议先导出资料备份。更新时不要卸载扩展，覆盖或重新加载后，本机资料和 API 设置会保留。

偏好设置

开启后，点击“开始填写”之后你在网页上修改或补填的字段会被记录下来，页面右下角会提示“N 处修改”，点开即可勾选写回本机资料库。关闭后仍可在弹窗里手动点击“更新资料库”对比一次。记录的值只保存在本机，写入前必须由你逐项确认。

选项匹配用于"全日制 vs 全日制本科"、"硕士 vs 硕士研究生"这类措辞不一致的下拉框和单选题。开启后，本地规则匹配不到选项时，会把该字段的资料值和页面选项列表发给你配置的 API。只对学历、学位、学习形式、政治面貌、婚姻状况、民族、城市、是否类等低敏感字段生效；姓名、电话、证件号、地址、学号、薪资、家庭成员等永远不会发送。默认关闭。

API 设置（可选，用于 AI 页面分析）

可用变量：{{modelJson}}、{{messagesJson}}、{{systemPromptJson}}、{{userPromptJson}}、{{profileJson}}、{{profileCatalogJson}}、{{fieldsJson}}、{{scanJson}}。其中 profile* 变量都是本地字段目录，不含具体值。
